# Limitations and discussion

## Scope of evidence

This is a reproducible exploratory extension of an existing four-input German Credit project. The preserved executable single-split experiment and the new matched-split study answer different questions. The five repeated-result means supplied in the task and the previously described five/six-input experiments have no corresponding execution artifacts in the original checkout. They must not be silently replaced or described as reproduced. A disagreement with an unavailable report cannot be diagnosed conclusively from this code alone.

Repeated stratified holdouts reuse observations. Their sample standard deviations measure split sensitivity, not uncertainty from five independent datasets. The paired summaries describe changes on matched partitions without an ordinary paired t-test. Conditional bootstrap intervals, where supplied, resample seed 42 test observations within class and hold fitted models, selected configurations and thresholds fixed. They omit training-set, model-selection and dataset-sampling uncertainty; they cannot establish a general significance claim. This small study uses many model/condition comparisons and is exploratory.

The original test outputs were known before the extension was designed. New model choices use only fitting and validation records within each split, which prevents direct computational test leakage, but it does not erase project-level adaptive reuse of this dataset. An independent final dataset or locked external holdout would strengthen confirmation. Splits have only 60 bad-credit test observations, making recall move in increments of 1/60.

## Optimization and comparison

Two candidate settings per tunable model offer limited and explicit access to validation data. They are not exhaustive tuning or equal FLOP budgets. MLP selects stopping epochs using validation balanced accuracy with an optimized threshold, while ANFIS selects its stopping epoch using a penalized validation loss before trial-level balanced-accuracy selection. Linear logistic regression solves a different optimization problem. The original fixed 500-step model has no stopping search. These protocol differences preclude claiming the best possible representative of any model family.

Fixed-premise ANFIS is logistic regression on a structured fuzzy basis: the fitting loss is convex in consequent coefficients absent clipping. A slow original gradient trajectory can support an optimization-budget concern, but does not show that every performance difference is caused by one optimizer choice. New fixed Adam also changes L2 regularization, stopping and normalization. The separate normalization-only check and validation-only learning-rate ablation narrow the diagnosis, but a full factorial optimizer/regularizer/stopping experiment was not run. Premise learning is nonconvex and initialized from training quantiles; learned centres may cross, so ordered linguistic names require checking. Width bounds and log-domain weights help numerical validity but do not ensure predictive performance.

The same resampled row indices and sample weights are available to all non-dummy models in each matched condition. New MLP uses the external validation set to avoid duplicate contamination in internal stopping. Weighted losses and oversampling change the effective training prior; sigmoid outputs are model scores in [0,1], not empirically calibrated repayment probabilities. Brier scores are reported descriptively. No deployment cost assumptions, fairness guarantee, calibration intervention or real lending advice follows from this benchmark.

## Data semantics and representativeness

Only four base variables are used, so these results do not assess what any model could achieve with all available credit information. Standardizing coded installment burden and applying smooth Gaussian/linear functions assumes ordered spacing in the numeric encoding. Residence and number-of-credit inputs in dimension experiments make the same assumption. A one-hot/ordinal alternative encoding study remains unfinished; a train-only ranking of a restricted candidate pool does not resolve it. The supplied `n_guarantors` name has no accompanying dictionary; its values are treated only as discrete codes for supplementary feature sensitivity and must not be interpreted as a verified count of guarantors.

[UCI's South German Credit documentation](https://archive.ics.uci.edu/dataset/573/south+german+credit+) warns of errors in the historical Statlog coding information and describes installment rate, residence and number of credits as discretized ordinal quantities. This is a warning about provenance and interpretation, not evidence that this CSV is the corrected South German dataset. The current work preserves the supplied CSV; it does not substitute a new dataset. Obtain and cite the original export provenance and mapping before assigning literal percentages, years or counts to every code.

The [Statlog repository](https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data) describes good/bad credit-risk classification. Historical benchmark accuracy is not contemporary credit-risk validation. There are no temporal splits, external validation populations, operational default horizons or dataset-specific harm assessments in this experiment.

## What explanations establish

Rule contributions exactly reconstruct a model logit. They describe the fitted mechanism, not a causal reason for default or a reason a bank should refuse credit. A positive contribution increases the logit relative to zero, not relative to a counterfactual customer or a population baseline. Contribution magnitude depends on standardization, linear coefficients and overlapping premise weights. Since sigmoid is nonlinear, summing individual sigmoids would be wrong. A negative total logit can still be classified as bad under a selected threshold below .5. Membership grades express compatibility with Gaussian sets and must never be called outcome probabilities.

Full grids require reading 81, 243 or 729 first-order rules with 4, 5 or 6 conditions each. Diffuse activation and near-duplicate quantile centres can make the inventory harder to interpret. Faithfulness tests are necessary but are not a human comprehension study. Two predetermined cases demonstrate reproducible local inspection, not universal interpretability or stability under changing fits.

## Connections to verified literature

[J.-S. R. Jang, 1993](https://scholars.lib.ntu.edu.tw/entities/publication/3b716e7c-a2e7-4ff2-9c28-2faf9ced327e), “ANFIS: Adaptive-Network-Based Fuzzy Inference System,” IEEE Transactions on Systems, Man, and Cybernetics, 23(3), 665–685, doi:10.1109/21.256541, presents adaptive-network fuzzy inference with hybrid learning. The original project's frozen Gaussian premises and consequent-only BCE descent are a simplified TSK classifier, not that full training procedure. New premise-gradient learning still does not implement the original hybrid least-squares procedure.

[J. Cao, T. Zhou, S. Lam, Y. Zhang, J. Zhang, X. Fan, D. Sun and J. Cai, 2025](https://scholars.duke.edu/publication/1678577), “A Lightweight TSK Fuzzy Classifier With Quantitative Equivalent Fuzzy Rules via Adaptive Weighting,” IEEE Transactions on Fuzzy Systems, 33(8), 2805–2817, doi:10.1109/TFUZZ.2025.3572937, addresses full-rule combination growth using adaptive weighting and a factorized consequent structure. Our full-grid parameter growth motivates that design concern; neither adaptive weighting nor the paper's factorization/least-learning-machine procedure is implemented here. No published performance value is used as a comparable benchmark.

[Y. Zhang, G. Wang, T. Zhou, G. Ren, S. Lam, W. Ding and J. Cai, 2024](https://scholars.duke.edu/publication/1643088), “Deep Reconciled and Self-Paced TSK Fuzzy System Ensemble for Imbalanced Data Classification: Architecture, Interpretability, and Theory,” IEEE Transactions on Fuzzy Systems, 32(11), 6185–6198, doi:10.1109/TFUZZ.2024.3442821, studies an ensemble with reconciled/self-paced sampling and interpretability concerns from stacking. Our weighting/oversampling controls test simpler imbalance interventions. They do not implement its sampling theory, deep ensemble or interpretability evaluation.

[A. V. Lakra, S. Jena and K. Mishra, 2025](https://researcher.manipal.edu/en/publications/optimizing-xgboost-hyperparameters-for-credit-scoring-classificat/), “Optimizing XGBoost Hyperparameters for Credit Scoring Classification using Weighted Cognitive Avoidance Particle Swarm,” IEEE Access, 13, 127292–127306, doi:10.1109/ACCESS.2025.3585980, concerns XGBoost hyperparameter optimization. It motivates transparent optimization budgets in credit-scoring research but provides no direct comparative result for this ANFIS architecture. No XGBoost or particle-swarm reproduction is claimed.
